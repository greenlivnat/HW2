# academic-review

Read chapters/*.txt and references.bib. Match each material claim to the primary passage and record its units, population, comparator and scope. Report issue IDs, exact source locations and corrected wording. Mark inaccessible sources unverified. Never infer a correction from an abstract alone when the full paper is available.
