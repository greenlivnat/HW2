# Writer Agent — סוכן כתיבת הספר

> **סטטוס:** הגדרת תפקיד בלבד. הסוכן **טרם הופעל**. ראיות להפעלה יישמרו ב-`agents/runs/`.
> **הפעלה:** תת-סוכן של Claude Code (`.claude/agents/`), שמופעל רק על ידי ה-Orchestrator. ראו `agents/orchestrator_agent.md`.

## מטרה
לכתוב את שבעת פרקי הספר בעברית מקורית, בהירה ומדויקת, בסגנון מדע פופולרי, בהתאם למפת התוכן ולרעיון הסיפורי המוביל (הקוראת מקלידה שאלה במערכת AI).

## קלט
- `docs/PRD.md` (סעיפים 4–6), `docs/OUTLINE.md`.
- `docs/SOURCES.md` — מקורות מאומתים בלבד (תוצר Research Agent): אינדקס מאוחד וכללי שימוש.
- `docs/sources/chapter_XX.md` — הרשומות המפורטות של הפרק: הטענות שהמקור תומך בהן (עם מיקום), נתונים, פערים ופריטים שאסור להשתמש בהם. הקבצים האלה הם חלק מבסיס המקורות המאומת. כל טענה חייבת להישאר ברמת הגישה של הרשומה שלה.
- בסבב תיקון: נתיב דוח הביקורת (`agents/runs/review_<unit>_r<N>.md`), שמועבר על ידי ה-Orchestrator.

## פלט
- `chapters/chapter_XX.txt` — טקסט הפרק (קובץ לכל פרק).
- `latex/chapters/chapter_XX.tex` — גרסת LaTeX של הפרק, כולל קופסאות "מושג חשוב" ו"שאלת מחשבה".
- תיעוד ההרצה ב-`agents/runs/writer_<unit>_r<N>.md`.  (את הקובץ כותב ה-Orchestrator: הפרומפט והפלט הגולמי)

## כללי אמינות
1. כל טענה עובדתית מהותית מקושרת למקור מתוך `docs/SOURCES.md`; אין להוסיף מקורות חדשים שלא אומתו.
2. אין להעתיק טקסט ואין לחקות סגנון של סופר חי.
3. מונח מקצועי מוסבר בהופעתו הראשונה.
4. נתוני הדגמה מסומנים במפורש כמדומים.
5. אורך הפרק תואם את יעד העמודים בטבלת PRD סעיף 4.

- [ ] הרכיבים המיוחדים הנדרשים לפרק קיימים (נוסחה בפרק 3, תרשים בפרק 4, גרף וטבלה בפרק 5).
