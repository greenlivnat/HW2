### טענות שהמקור תומך בהן
1. **שאלת היסוד של למידת מכונה** (סעיף 1, Defining Questions, עמ' 1): "How can we build computer systems that automatically improve with experience, and what are the fundamental laws that govern all learning processes?"
2. **ההגדרה הפורמלית של "לומדת" (T, P, E)** (סעיף 1, עמ' 1): "we say that a machine *learns* with respect to a particular task T, performance metric P, and type of experience E, if the system reliably improves its performance P at task T, following experience E."
3. **תוכנה רגילה מול למידת מכונה** (סעיף 1, עמ' 1): "Whereas Computer Science has focused primarily on how to manually program computers, Machine Learning focuses on the question of how to get computers to program themselves (from experience plus some initial structure)."
4. **למידת מכונה כצומת של מדעי המחשב וסטטיסטיקה** (סעיף 1, עמ' 1): "Machine Learning is a natural outgrowth of the intersection of Computer Science and Statistics."
5. **למה ללמד ולא לתכנת: זיהוי דיבור** (סעיף 2.1, Application Successes, עמ' 2): "the speech recognition accuracy is greater if one trains the system, than if one attempts to program it by hand."
6. **ראייה ממוחשבת** (סעיף 2.1, עמ' 2): מערכות ראייה מפותחות בלמידת מכונה "because the resulting systems are more accurate than hand-crafted programs."
7. **נתונים (נכונים לשנת 2006, ראו סעיף הדוגמאות):** "as late as 1985 there were almost no commercial applications of machine learning" (סעיף 2.1). "Over 85% of handwritten mail in the US is sorted automatically, using handwriting analysis software trained to very high accuracy using machine learning" (סעיף 2.1, Computer vision).

1. **הגדרה של Nils J. Nilsson** (שהדוח מצטט): "Artificial intelligence is that activity devoted to making machines intelligent," + "intelligence is that quality that enables an entity to function appropriately and with foresight in its environment."

### "נוסחה" מושגית: התבנית T / P / E (מבוססת על S-ch01-03, סעיף 1)
ההגדרה ב-S-ch01-03 מילולית ואינה נוסחה מתמטית. אפשר להציג אותה כמבנה של שלושה רכיבים:
- **T** (task): המשימה.
- **P** (performance metric): מדד הביצוע.
- **E** (experience): סוג הניסיון.

המערכת "לומדת" אם P משתפר ב-T אחרי E.
**דוגמה שמבוססת על המקור:** זיהוי דיבור. לפי S-ch01-03 (סעיף 2.1), מערכות זיהוי דיבור מאומנות כי הדיוק גבוה יותר מאשר בתכנות ידני. **מיפוי T/P/E לדוגמה הזו** (T = תמלול דיבור, P = דיוק הזיהוי, E = הקלטות לדוגמה) הוא **הצעה פרשנית של הסוכן**, והמקור לא מנסח אותו כך.

## רעיונות להמחשה (הצעות)

> כל הרעיונות כאן הם **הצעות של Research Agent** ולא עובדות מהמקורות.

1. **מפת מושגים בעיגולים מקוננים (הרכיב החזותי של הפרק לפי OUTLINE):** עיגול חיצוני "בינה מלאכותית" (D1/D2), בתוכו "למידת מכונה" (D4), ובתוכו "למידה עמוקה" (D5/D6). ליד כל עיגול משפט הגדרה קצר עם מזהה מקור. **הערה:** היחס "למידה עמוקה ⊂ למידת מכונה ⊂ AI" מקובל, ו-S-ch01-08 מציג את למידת המכונה כמנוע של AI ואת הלמידה העמוקה כסוג של רשתות נוירונים. אבל אף מקור מאומת לא מצייר את ההיררכיה הזו במפורש (ראו פערים).
2. **תרשים השוואה בשני מסלולים:** "תוכנה רגילה": כללים + נתונים → תוכנית → תשובות. מול "למידת מכונה": דוגמאות (נתונים + תשובות רצויות) → אימון → מודל → תשובות לנתונים חדשים. התרשים מבוסס על E1 ו-E2. **המבנה הגרפי הוא הצעה.**
3. **קופסת "מושג חשוב": T / P / E** עם דוגמה יומיומית (למשל מסנן דואר זבל). **הדוגמה עצמה לא מופיעה במקורות המאומתים**, ולכן יש להציג אותה כהמחשה ולא כציטוט.
4. **ציר זמן קטן:** 1950 (טיורינג) ← 1955/1956 (דרטמות') ← 1959 (Samuel: כותרת בלבד) ← 2015 (סקירת Deep learning) ← 2019/2024 (הגדרת OECD).
5. **קופסת "שאלת מחשבה":** "האם מחשבון הוא בינה מלאכותית?" (E5), יחד עם "אפקט ה-AI" (E6).
