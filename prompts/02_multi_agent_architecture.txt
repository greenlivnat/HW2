עדכון חשוב לדרישות הפרויקט:

הפרויקט צריך להתבסס על ארכיטקטורת Multi-Agent הכוללת ארבעה סוכנים:

1. Orchestrator Agent
2. Research Agent
3. Writer Agent
4. Reviewer Agent

סוכן ה-Orchestrator יהיה סוכן-העל האחראי להפעלת שלושת הסוכנים האחרים, חלוקת משימות, ניהול תלויות, העברת מידע, בקרת איכות וניהול מחזורי תיקון.

הגדר את Claude Code הראשי כ-Orchestrator ואת שלושת הסוכנים האחרים כתתי-סוכנים עצמאיים.

עדכן בהתאם את הקבצים וההגדרות הבאים:

- PRD.md
- README.md
- CLAUDE.md
- agents/orchestrator_agent.md
- הגדרות תתי-הסוכנים בתיקיית .claude/agents/
- PROMPT_HISTORY.md

הגדר מנגנון שבו סוכן הביקורת יכול להחזיר תוצרים לסוכן הכתיבה לתיקון באמצעות סוכן-העל.

תעד את ארכיטקטורת הסוכנים ואת תהליך העבודה ביניהם.

בהמשך יש להפעיל את הסוכנים בפועל ולשמור תיעוד אמיתי של הרצותיהם.
